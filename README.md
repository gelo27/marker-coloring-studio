# Marker Coloring Studio

Розмальовка → satisfying-ролик: фломастер (або інший інструмент) зафарбовує сторінку, камера знімає, на виході MP4/WebM зі звуком.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (доступно й з телефону в тій самій мережі)
npm run build      # збірка в dist/
npm run preview    # перегляд зібраної версії
npm run lint       # ESLint: неоголошені змінні, присвоєння імпортам
```

Потрібен браузер із WebGL; покадровий рендер відео використовує WebCodecs (Chrome, Edge, Safari 17+). Без нього студія пише WebM у реальному часі.

## Структура

```
index.html                 розмітка: сцена, покроковий режим, розширені налаштування
src/main.js                запуск і прив'язка елементів керування
src/core/                  дані й алгоритми без рендеру
  settings.js              інструменти, характер руки, ефекти, налаштування (S, VS, FLY, OUT, PREV…)
  segment.js               розбиття сторінки на зони, виділення контуру з зафарбованої картинки
  zones.js                 зони, палітра, порядок (зокрема групами кольорів), тони/тіні/відблиски з оригіналу
  strokes.js               траєкторії руки: штриховка, контур за контуром, кола, латки, домальовування
  plan.js                  розклад у часі, плани камери, склейки, проліт, об'ємні тіні
  utils.js                 дрібні помічники
src/render/                PixiJS: сцена, фарба, рідина, блискітки, камера, заставка
  shaders/*.frag|vert      GLSL (папір, стіл, пост-ефекти)
  toolSprites.js           фотореалістичні інструменти (токарний профіль) і контактна тінь
src/audio/                 процедурний ASMR-звук
src/editor/editor.js       редактор зон (тап, пінч-зум, режими «фарбувати» і «пензлик налаштувань»)
src/ui/                    панелі: покроковий майстер, інспектор, відтворення, проєкт, експорт
src/data/                  демо-сторінка, шрифти Hershey для заставки
```

Стан, який змінюють кілька модулів, належить одному модулю й змінюється через його сетери (`setPlan…`, `setBusy`, `setT`, `setCustomOrder`…). `npm run lint` ловить прямі присвоєння імпортам.

## Можливості

- **Покроково**: картинка (drag & drop) → перевірка зон → кольори тапом (з undo) → порядок групами кольорів → камера й швидкість пензликом → відео з пресетами.
- **Усі налаштування**: повний набір керування з попередньої версії.
- Зафарбована картинка: база, тіні й відблиски кожної зони; білі відблиски лишаються папером; перефарбування зберігає тіні.
- «Склейка»: зона не малюється в кадрі, а з'являється готовою на монтажній склейці.
- Камера «Перо крупно»: макроплан, у кадрі завжди лише передня половина інструмента.
- Превʼю «Легке / Ефекти / Повне» для телефонів.
- На телефоні: іконки режимів по боках канвасу, таймлайн зон із плейхедом по центру (свайп — перемотка, пінч — масштаб), повний екран, нижня панель кроків.
